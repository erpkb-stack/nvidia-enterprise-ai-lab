# Roadmap
1. Foundation: dashboard, API, project persistence, architecture blueprint, catalogs (included).
2. RAG: safe upload, parsing, chunking, embeddings, Qdrant, retrieval, reranking, evaluation.
3. Serving: provider-specific NIM API, Triton model repository, streaming, tracing, registry.
4. Operations: NeMo workflow, Kubernetes client, GPU Operator checks, Run:ai connector.
5. Benchmark/OEM: repeatable hardware harness, telemetry, validation reports, presentation mode.
6. Hardening: OIDC, RBAC, tenant isolation, audit retention, secrets manager, scanning, backups, load testing.
